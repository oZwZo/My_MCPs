# Google Scholar 搜索模式使用示例

## 1. 快速模式 - 快速查找文献

**场景**: 初步了解某个研究主题

```python
# 使用方法（在Claude Code中）
"搜索 Google Scholar 关于 'CRISPR gene editing' 的文献（快速模式）"

# 或者直接指定参数
"搜索 Google Scholar 关于 'machine learning in biology' 的前10篇文献"
```

**返回**: 前10篇最相关的文献
**用时**: ~2秒
**适用**: 快速浏览、初步调研

---

## 2. 相关度优化模式 - 获取更全面的结果

**场景**: 需要全面了解某个领域的核心文献

```python
# 在Claude Code中使用
"使用Google Scholar相关度优化模式搜索 'hematopoietic stem cell' 的文献"

# 指定返回20篇
"使用Google Scholar相关度优化模式搜索 'single cell sequencing' ，返回前20篇"
```

**返回**: 从前200篇中筛选的最相关文献
**用时**: ~5-10秒
**适用**: 文献综述、全面搜索

---

## 3. 深度查找模式 - 获取最高质量的文献

**场景**: 寻找高影响力、最新的核心文献

```python
# 在Claude Code中使用
"使用Google Scholar深度查找模式搜索 'CRISPR gene editing' 的最优文献"

# 查看详细评分
"使用深度模式搜索 'artificial intelligence drug discovery'，并显示评分详情"
```

**返回**: 综合评分最高的5篇文献
**用时**: ~15-30秒
**适用**: 论文写作、深入研究

**返回信息包括**:
- 标题、摘要、作者、期刊
- 引用次数
- 三维度评分：
  - 引用度（被引用程度）
  - 相关度（与查询的相关性）
  - 时效性（发表时间，越新越好）
  - 总分（加权综合评分）

## 使用建议

### 工作流程示例

**场景**: 准备写一篇关于"CRISPR在基因治疗中的应用"的综述

1. **第一步 - 快速扫描**
   ```
   使用快速模式搜索 "CRISPR gene therapy"
   ```
   了解大致情况，确认研究方向

2. **第二步 - 全面搜集**
   ```
   使用相关度优化模式搜索 "CRISPR gene therapy clinical trials"，返回30篇
   ```
   获取更全面的文献集

3. **第三步 - 精选核心文献**
   ```
   使用深度查找模式搜索 "CRISPR gene therapy"
   ```
   获取引用次数高、相关性强的最新核心文献

### 各模式对比

| 特性 | 快速模式 | 相关度优化模式 | 深度查找模式 |
|------|---------|---------------|-------------|
| 搜索范围 | 前10篇 | 前200篇 | 扩展到200-300篇 |
| 用时 | <2秒 | 5-10秒 | 15-30秒 |
| 排序依据 | 默认排序 | 相关度 | 多维度综合评分 |
| 适用场景 | 快速查询 | 全面搜索 | 深度研究 |
| API调用次数 | 1次 | 10次 | 10-20次 |

### 评分解读（深度模式）

**引用度** (0-1)
- 0.9-1.0: 高影响力文献（被引用次数很多）
- 0.7-0.9: 中等影响力
- 0.5-0.7: 一般影响力
- <0.5: 影响力较低

**相关度** (0-1)
- 0.9-1.0: 非常相关
- 0.7-0.9: 较相关
- 0.5-0.7: 一般相关
- <0.5: 相关性较低

**时效性** (0-1)
- 0.9-1.0: 最近1-2年的文献
- 0.7-0.9: 最近3-5年
- 0.5-0.7: 最近5-10年
- <0.5: 10年以前的文献

**总分** (0-1)
- >0.85: 强烈推荐，必读文献
- 0.75-0.85: 高质量文献，值得精读
- 0.65-0.75: 较好文献，可以参考
- <0.65: 一般文献，选择性阅读

## 高级技巧

### 1. 组合使用

先用快速模式确认关键词，再用深度模式获取核心文献：
```
"先快速搜索 'CRISPR delivery'，然后对最相关的前3个主题分别使用深度模式搜索"
```

### 2. 对比不同子主题

```
"使用深度模式分别搜索 'CRISPR base editing' 和 'CRISPR prime editing'，对比两者的核心文献"
```

### 3. 追踪最新进展

深度模式会优先推荐新文献：
```
"使用深度模式搜索 'AI drug discovery'，只看2024年后的高分文献"
```

## 注意事项

1. **API配额**: 深度模式会消耗更多API调用，请合理使用
2. **搜索时间**: 深度模式需要15-30秒，请耐心等待
3. **结果质量**: 深度模式返回的文献质量更高，但数量较少
4. **网络稳定性**: 确保网络连接稳定，避免中途失败

---

## 问题排查

### 问题: 深度模式返回错误
**解决**: 检查SerpApi密钥是否有效，是否有足够的配额

### 问题: 搜索结果不相关
**解决**: 尝试调整搜索关键词，使用更具体或更通用的术语

### 问题: 找不到最新文献
**解决**: 使用深度模式，时效性权重会优先推荐新文献

### 问题: 想要更多结果
**解决**: 先用相关度优化模式获取更多文献，再用深度模式从其中筛选
